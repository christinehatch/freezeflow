# Page Framework

## Purpose

Freezeflow pages use a consistent narrative:

**Orient → Focus → Act → Reveal**

This is a hierarchy, not a rigid template. A page may omit a region when it has
nothing useful to show.

## Orient

Start with:

- one page title
- one sentence explaining the page's purpose or current state
- optional quiet context such as a Batch identifier

The header should help the user understand where they are without exposing
internal implementation concepts.

## Focus

Present the task, state, or information that deserves attention now.

Use one focused surface when the page needs to communicate calm, attention,
success, or danger. Avoid multiple competing banners.

## Act

Provide one clear primary action when an action is available.

Secondary, quiet, and destructive actions should remain visually subordinate.
The primary action must preserve the documented workflow and current context.

## Reveal

Show secondary information with quieter visual weight:

- details
- history
- setup or administration
- optional explanations
- less common actions

Use sections, disclosure, or supporting surfaces rather than giving every fact
the same emphasis.

## Page layout

- Use the shared maximum content width and responsive page padding.
- Keep the title and primary action visually connected.
- Use consistent vertical spacing between page regions.
- Let content reflow naturally; do not depend on fixed desktop dimensions.
- Preserve usable touch targets and reading order on small screens.
